# v0.4.0 — Routing Primitives (issues #20, #21-redaction, #26)

**Phase 2 of the master plan** (`docs/superpowers/plans/2026-05-28-master-plan-issues-18-26.md`, lines 141–183). Ships on top of a green v0.3.2 tree; branch is still the long-running `next` off `main` per locked decision #1.

## Goal

Land three new routing primitives on top of ONE shared fan-out refactor of `send-message.sh`:

1. **Multi-recipient broadcast** (#20) — `send-message.sh all|* <type> <content>` or `--to id1,id2,id3` delivers to N inboxes in one invocation. Auto-creates N conversations for conversation-bearing types (one thread per recipient) per locked decision #3.
2. **`--cc` recipient-role tagging** (#26) — `--cc id1,id2` copies the message to CC'd recipients in a **shared** conversation, and tags each delivered copy with `metadata.recipientRole = "primary" | "cc"`. Receiver-side (`check-inbox.sh`, `bridge-listen.sh`) surfaces the role and prepends `[CC informational — no response required]` for `role=cc` copies.
3. **Opt-in content redaction** (#21-redaction) — `--redact` scrubs a conservative pattern set (AWS keys, Stripe live/test secrets, GitHub PATs, Slack bot tokens) BEFORE the message is written to any inbox or outbox. `BRIDGE_REDACT_PATTERNS_FILE` env override for user-supplied additions. Default OFF per locked decision #2.

The three features share one foundation: `scripts/lib/fanout.sh` with `_deliver_one(msg-json, target-inbox, sender-outbox)` as a **pure** per-recipient helper (no notification side effects — stale-recipient notifications stay in the caller's loop body per critique C7). `send-message.sh` becomes a thin driver that (a) parses recipients, (b) resolves conversations, (c) applies redaction, (d) loops over recipients calling `_deliver_one`, (e) emits JSON stdout.

  ```bash
  _deliver_one() {
    local msg_json="$1"
    local target_inbox="$2"
    local sender_outbox="$3"
    local msg_id
    msg_id=$(echo "$msg_json" | jq -r '.id')

    [ -d "$target_inbox" ] || return 1

    local tmp
    tmp=$(mktemp "$target_inbox/$msg_id.XXXXXX") || return 1
    echo "$msg_json" > "$tmp"
    mv "$tmp" "$target_inbox/$msg_id.json" || { rm -f "$tmp"; return 1; }

    if [ -d "$sender_outbox" ]; then
      local outbox_json tmp2
      outbox_json=$(echo "$msg_json" | jq '.status = "sent"')
      tmp2=$(mktemp "$sender_outbox/$msg_id.XXXXXX") || return 2
      echo "$outbox_json" > "$tmp2"
      mv "$tmp2" "$sender_outbox/$msg_id.json" || { rm -f "$tmp2"; return 2; }
    fi

    return 0
  }

  parse_csv_recipients() {
    local csv="$1"
    [ -n "$csv" ] || return 1
    local IFS=','
    local id
    for id in $csv; do
      id="${id// /}"   # trim spaces
      [ -n "$id" ] || continue
      if ! [[ "$id" =~ ^[a-z0-9]{6}$ ]]; then
        echo "Error: invalid recipient id '$id' (must match ^[a-z0-9]{6}$)" >&2
        return 1
      fi
      echo "$id"
    done
  }

  expand_recipients() {
    local token="$1"
    local sender_id="${BRIDGE_SESSION_ID:?BRIDGE_SESSION_ID required}"
    local script_dir="${BRIDGE_SCRIPT_DIR:-$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)}"

    case "$token" in
      all|'*')
        BRIDGE_DIR="${BRIDGE_DIR:-$HOME/.claude/session-bridge}" \
          bash "$script_dir/list-peers.sh" "$sender_id" --ids-only \
          | grep -v "^$sender_id\$" || return 1
        ;;
      *,*)
        parse_csv_recipients "$token" || return 1
        ;;
      *)
        if [[ "$token" =~ ^[a-z0-9]{6}$ ]]; then
          echo "$token"
        else
          echo "Error: invalid recipient token '$token'" >&2
          return 1
        fi
        ;;
    esac
  }
  ```

## Task 3: `--cc` recipient-role tagging (#26) — shared conversation, `metadata.recipientRole`, receiver-side prefix

## Task 4: Opt-in `--redact` content scrubbing (#21-redaction) — conservative pattern set, env override

**Rationale.** Task 8 of v0.3.2 documented the plaintext-persistence threat model ("do not send raw credentials"). This task ships the mechanical enforcement: `--redact` scrubs the content string BEFORE it's written to any inbox or outbox, so accidental secrets are neutralized on disk. Per locked decision #2 the default is OFF — false positives with email/JWT patterns are too costly for an always-on default, and the SKILL.md guidance ("pass file paths, not content") remains the primary control.

The pattern set is deliberately narrow. Five entries in v0.4.0:

1. `AKIA[0-9A-Z]{16}` — AWS access key ID prefix
2. `sk_live_[a-zA-Z0-9]{20,}` — Stripe live secret key
3. `sk_test_[a-zA-Z0-9]{20,}` — Stripe test secret key
4. `github_pat_[A-Za-z0-9_]{22,}` — GitHub fine-grained PAT
5. `xoxb-[A-Za-z0-9-]{20,}` — Slack bot token

No email, no JWT, no generic `password=`. Users needing more provide their own file via `BRIDGE_REDACT_PATTERNS_FILE=/path/to/patterns`. The bundled defaults live at `plugins/session-bridge/scripts/lib/redact-patterns.default` (one regex per line, `#`-prefixed comments allowed).

Redaction produces a single sentinel: `[REDACTED]`. The count of substitutions goes into `metadata.redactionCount` on the delivered message so receivers can see that redaction happened. Field is absent (not zero) when `--redact` was not used.

  ```bash
  #!/usr/bin/env bash
  # scripts/lib/redact.sh — content redaction with a conservative default
  # pattern set. Opt-in via --redact flag or BRIDGE_REDACT=1 env in
  # send-message.sh. Pattern set defined in redact-patterns.default; override
  # via BRIDGE_REDACT_PATTERNS_FILE=/path/to/patterns.

  redact_content() {
    local content="$1"
    local default_patterns="${BASH_SOURCE[0]%/*}/redact-patterns.default"
    local patterns_file="${BRIDGE_REDACT_PATTERNS_FILE:-$default_patterns}"

    if [ ! -f "$patterns_file" ]; then
      echo "Warning: redact patterns file not found: $patterns_file; falling back to defaults" >&2
      patterns_file="$default_patterns"
      [ -f "$patterns_file" ] || { echo "Error: default patterns file missing" >&2; REDACTION_COUNT=0; echo "$content"; return 1; }
    fi

    local pattern count total=0 result="$content"
    while IFS= read -r pattern; do
      [ -z "$pattern" ] && continue
      [[ "$pattern" =~ ^[[:space:]]*# ]] && continue
      # Count matches BEFORE substitution
      count=$(echo "$result" | grep -oE "$pattern" | wc -l)
      total=$((total + count))
      # Substitute (sed extended regex)
      result=$(echo "$result" | sed -E "s#${pattern}#[REDACTED]#g")
    done < "$patterns_file"

    REDACTION_COUNT=$total
    echo "$result"
  }
  ```
