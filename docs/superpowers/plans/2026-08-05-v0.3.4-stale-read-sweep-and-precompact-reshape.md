  # Sweep any status:"read" files from the inbox into .delivered/ silently.
  # Defensive fix for #29: a pre-v0.2.17 cached check-inbox.sh briefly in
  # effect on the running plextura orchestrator (2026-07-17 through
  # 2026-07-29 per the Local Plugin Cache Quirk) rewrote each incoming
  # message with .status = "read" instead of archiving. Those files sit
  # in inbox/ forever because current scan filters reject anything not
  # status:"pending". This sweep silently moves them (no re-injection —
  # the model already saw them when the old code injected them).
  _sweep_stale_read() {
    local INBOX="$1"
    [ -d "$INBOX" ] || return 0
    local F STATUS SWEPT=0 ARCHIVE_DIR="$INBOX/.delivered"
    for F in "$INBOX"/*.json; do
      [ -f "$F" ] || continue
      STATUS=$(jq -r '.status // ""' "$F" 2>/dev/null || echo "")
      [ "$STATUS" = "read" ] || continue
      mkdir -p "$ARCHIVE_DIR" 2>/dev/null
      if mv "$F" "$ARCHIVE_DIR/$(basename "$F")" 2>/dev/null; then
        SWEPT=$((SWEPT + 1))
      fi
    done
    [ "$SWEPT" -gt 0 ] && _log "SWEEP stale-read count=$SWEPT inbox=$INBOX"
    return 0
  }

## Task 2: Reshape `--summary-only` emission for PreCompact

**Rationale.** v0.3.3 Task 1's decompiled Claude Code v2.1.211 investigation confirmed: PreCompact's `Vge` aggregator uses raw stdout as literal "compaction instructions." It does NOT parse `hookSpecificOutput` or read `.systemMessage`. So `--summary-only`'s current `jq -n '{continue, suppressOutput, systemMessage: $msg}'` emission has the SUMMARY BURIED INSIDE a JSON envelope, and the entire blob becomes compaction instructions — the model sees `{"continue":true,"suppressOutput":false,"systemMessage":"=== CLAUDE BRIDGE STATE === ..."}` as its guidance on how to compact.

Fix: emit the summary as clean stdout text for PreCompact (raw text, no JSON envelope), so it reaches the model in the intended shape. The `continue: true` semantics are meaningless to PreCompact anyway (it doesn't consume that field). Keep a JSON emission path for any future non-PreCompact caller of `--summary-only` (there are none today; hooks.json only wires it to PreCompact).
